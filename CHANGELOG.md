# История изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.2.0] — 2026-10-19

### Добавлено
- **Гибридный источник звука.** Каждый трек скачивается через API SoundCloud в лучшем качестве: оригинальный файл автора (если разрешён) или лучший полный поток. Через плеер сайта трек скачивается, только если API отдаёт его 30-секундным превью без действующей сессии или если загрузка через API сорвалась.
- Если API не может разобрать ссылку, данные берутся со страницы SoundCloud.
- В настройки вернулись «Оригинальный файл» и «Предпочтительный кодек».
- В окне расширения видно качество трека, «Оригинальный файл» или «через плеер».
- Юнит-тесты (`npm test`), smoke-тест с реальным API (`npm run smoke`), CI и релизы через GitHub Actions.
- LICENSE, политика конфиденциальности, инструкции для публикации в магазинах.

### Изменено
- Сборка складывает архивы в `dist/` и проверяет, что версии в манифестах и `package.json` совпадают.

### Исправлено
- Без входа треки снова скачиваются: API не требует входа для большинства треков.
- Если SoundCloud отдаёт вашему аккаунту только превью (трек Go+), об этом сразу сообщается, и плеер не запускается впустую.

## [1.1.0] — 2026-10-19

### Добавлено
- Скачивание через плеер сайта (`content/page-hook.js`) вместо API.
- Кнопка «Скачать» в шапке системных подборок (Discover, миксы, чарты) и в нижнем плеере.
- Короткие ссылки `on.soundcloud.com`.

### Изменено
- В ZIP плейлиста треки лежат сразу в корне архива, без вложенной папки.

## [1.0.0] — 2026-10-19

### Добавлено
- Первая версия: треки, плейлисты, альбомы и профили через API SoundCloud.
- Обложка, теги ID3, MP4, FLAC, Ogg, текст песни из описания.
- ZIP для плейлистов, шаблоны имён, контекстное меню, версии для Chrome и Firefox.
