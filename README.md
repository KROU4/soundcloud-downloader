# SoundCloud Downloader

Расширение для Chrome и Firefox: скачивает треки, плейлисты, альбомы и все треки профиля с soundcloud.com. Файлы сохраняются с обложкой, тегами (исполнитель, название, альбом, год, жанр, номер трека) и текстом песни, если он есть в описании.

Расширение не обращается к API SoundCloud. Звук берётся из того же потока, который загружает плеер сайта: расширение нажимает кнопку воспроизведения на странице, перехватывает ссылку на поток и сохраняет его целиком. Ключи, `client_id` и токены не используются.

## Возможности

- Кнопка **«Скачать»**:
  - рядом с Like/Repost на странице трека, плейлиста и альбома;
  - у каждого трека в ленте, поиске и списках;
  - в шапке системных подборок: Discover, миксы, чарты;
  - в нижнем плеере, справа от Like / Follow / Next up. Она скачивает трек, который сейчас загружен в плеер.
- Плейлисты, альбомы и профили скачиваются одним ZIP-архивом. Треки лежат прямо в архиве, без вложенной папки, вместе с `cover.jpg` и плейлистом `.m3u8`.
- Через меню расширения можно вставить ссылку, в том числе короткую `on.soundcloud.com/…`. Пункт «Скачать с SoundCloud» есть и в контекстном меню.
- Шаблоны имён файлов и папок, размер обложки, параллельность — в настройках расширения.

## Требования

- **Вход на soundcloud.com в этом браузере.** Без входа сайт не даёт плееру воспроизводить треки, и расширение сразу об этом сообщает.
- **Открытая вкладка SoundCloud.** Расширение работает через плеер на ней: на время скачивания оно запускает треки без звука и потом ставит плеер на паузу. Если вы в этот момент слушаете другой трек, воспроизведение прервётся.
- **Браузер:** Chrome, Edge, Яндекс Браузер, Opera или Brave версии 116 и новее, либо Firefox 128 и новее.

## Ограничения

- **Качество.** Сохраняется поток, который выбирает плеер. Обычно это AAC 160 kbps (файл `.m4a`), у некоторых треков только 96 kbps. Скачать оригинальный файл автора (WAV/FLAC) без API нельзя.
- **Go+.** Треки только для подписчиков Go+ без подписки отдаются как 30-секундное превью: расширение их не сохраняет и пишет причину.
- **DRM.** Треки, которые SoundCloud отдаёт только в зашифрованном виде, сохранить нельзя.

## Установка

Готовые архивы лежат в [Releases](../../releases): `soundcloud-downloader-chrome-<версия>.zip` и `soundcloud-downloader-firefox-<версия>.zip`.

### Chrome, Edge, Яндекс Браузер, Opera, Brave

1. Скачайте `soundcloud-downloader-chrome-<версия>.zip` и распакуйте в постоянную папку, например `Документы\SoundCloud Downloader`. Папку потом не удаляйте: браузер загружает расширение прямо из неё.
2. Откройте страницу расширений:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - Яндекс Браузер: `browser://extensions`
   - Opera: `opera://extensions`
3. Включите **«Режим разработчика»** (переключатель справа вверху или слева внизу).
4. Нажмите **«Загрузить распакованное расширение»** и выберите распакованную папку (ту, где лежит `manifest.json`).
5. Закрепите значок на панели (иконка пазла → булавка) и обновите открытые вкладки SoundCloud.

Чтобы обновить расширение, распакуйте новую версию в ту же папку с заменой файлов, нажмите «Обновить» (круговая стрелка) на карточке расширения и перезагрузите вкладки SoundCloud.

Chrome при запуске может предупреждать о расширениях в режиме разработчика. Это нормально для расширений не из магазина, предупреждение можно закрыть.

### Firefox

Firefox постоянно устанавливает только подписанные расширения.

- **Временно, до перезапуска браузера.** Откройте `about:debugging#/runtime/this-firefox`, нажмите «Загрузить временное дополнение…» и выберите `soundcloud-downloader-firefox-<версия>.zip` (или `manifest.json` из распакованной папки).
- **Постоянно.** Нужен подписанный файл `.xpi`. Его можно бесплатно получить на addons.mozilla.org как «unlisted»-дополнение: оно не публикуется в каталоге, но устанавливается у кого угодно. Как это сделать, описано ниже в разделе «Подпись для Firefox».

## Настройки

Значок расширения → шестерёнка:

- **Папка внутри «Загрузок»:** по умолчанию `SoundCloud`.
- **Имя файла трека.**
- **Имя ZIP-архива плейлиста.**
- **Имя файла в плейлисте.**

Шаблоны подставляют поля `{artist}`, `{title}`, `{album}`, `{year}`, `{genre}`, `{index}`, `{playlist}`, `{playlistArtist}`, `{uploader}`, `{id}`.

Там же настраиваются:

- размер обложки;
- аватар автора вместо обложки, если обложки нет;
- название плейлиста в качестве альбома;
- разделение «Исполнитель - Название»;
- текст песни из описания;
- ZIP для плейлистов;
- `cover.jpg` и `.m3u8`;
- число одновременных загрузок.

## Как это устроено

| Файл | Роль |
|---|---|
| `content/page-hook.js` | Работает в контексте страницы (MAIN world) с момента её загрузки. Запоминает данные треков и плейлистов, которые загружает сам сайт, и ссылку на поток, которую получает плеер. Нажимает кнопки воспроизведения сайта, на это время выключает звук и потом ставит плеер на паузу. |
| `content/content.js` | Добавляет кнопки «Скачать» и передаёт запросы между расширением и `page-hook.js`. |
| `engine/page-source.js` | Получает у вкладки данные и ссылки на потоки. При необходимости открывает в ней нужную страницу и прокручивает список до конца. |
| `engine/engine.js` | Очередь заданий: скачивание HLS-потока, сборка `.m4a`, запись тегов и обложки, ZIP. |
| `background.js` | Работа с вкладками, загрузками и настройками. В Chrome движок работает в offscreen-документе `engine/host.html`, в Firefox — прямо в фоновой странице. |
| `lib/` | Теги ID3, MP4, FLAC, Ogg, RIFF; ZIP; разбор HLS; шаблоны имён. |

## Разработка

Исходники Chrome-версии лежат в `chrome/`, это главная копия. `firefox/` содержит те же файлы, отличаются только `manifest.json` и отсутствие `engine/host.*`.

```bash
node tools/build.mjs
```

Эта команда копирует общие файлы из `chrome/` в `firefox/` и собирает `soundcloud-downloader-chrome-<версия>.zip` и `soundcloud-downloader-firefox-<версия>.zip` в корне проекта. Версию меняйте в обоих `manifest.json`.

```bash
node tools/build.mjs --check
```

Эта команда только проверяет, что `firefox/` совпадает с `chrome/`.

Проверить Firefox-сборку:

```bash
npx web-ext lint --source-dir firefox
```

### Подпись для Firefox

1. Создайте API-ключи на https://addons.mozilla.org/developers/addon/api/key/ (нужен аккаунт Firefox).
2. Подпишите расширение:

   ```bash
   npx web-ext sign --source-dir firefox --channel unlisted --api-key <JWT issuer> --api-secret <JWT secret>
   ```

3. Готовый `.xpi` появится в `web-ext-artifacts/`. Его можно раздавать: при открытии в Firefox он устанавливается постоянно.

## Ответственность

Расширение предназначено для личного использования: офлайн-прослушивания музыки, которую вы и так можете слушать на SoundCloud. Уважайте права авторов и условия использования SoundCloud.
