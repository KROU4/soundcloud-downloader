# Публикация в магазинах расширений

Всё, что понадобится для публикации:

- **Пакеты.** Соберите командой `node tools/build.mjs` или скачайте из [Releases](../../../releases/latest):
  - `dist/soundcloud-downloader-chrome-<версия>.zip` — для Chrome Web Store, Edge Add-ons, Opera;
  - `dist/soundcloud-downloader-firefox-<версия>.zip` — для addons.mozilla.org.
- **Картинки** в папке [`store/`](../store):
  - иконка `icon-128.png`;
  - скриншоты 1280×800 `screenshot-*.png`;
  - малая промо-плитка `promo-small-440x280.png`;
  - большая плитка `promo-marquee-1400x560.png`.
- **Тексты и обоснования разрешений** — ниже в этом файле.
- **Ссылка на политику конфиденциальности.** Магазины требуют публичный URL. Пока репозиторий приватный, ссылка на `PRIVACY.md` для них не откроется. Подойдёт любой вариант:
  - сделать репозиторий публичным: Settings → General → Danger Zone → Change visibility. Тогда ссылка будет `https://github.com/KROU4/soundcloud-downloader/blob/main/PRIVACY.md`;
  - опубликовать `PRIVACY.md` как публичный gist (https://gist.github.com) и дать ссылку на него.

## Перед подачей: риски модерации

- **Права на контент.** Магазины, особенно Chrome Web Store, могут отклонить или позже снять расширение, которое скачивает контент со стороннего сервиса. Похожие расширения для SoundCloud в магазинах есть, но гарантии нет: возможна жалоба правообладателя. Firefox Add-ons к таким расширениям лояльнее.
- **Товарный знак в названии.** Название «SoundCloud Downloader» начинается с чужого товарного знака. Правила магазинов допускают форму «… for SoundCloud». Если модерация придерётся, поменяйте `name` в обоих `manifest.json` на «Downloader for SoundCloud» и пересоберите.
- **Скрытая публикация.** Чтобы не светиться в поиске, публикуйте как **Unlisted** (Chrome, Edge) или **Unlisted / On your own** (Firefox): установить можно только по прямой ссылке. Модерацию Chrome и Edge при этом всё равно нужно пройти. Firefox подписывает Unlisted-версии автоматически за несколько минут.

## Chrome Web Store

1. Зарегистрируйтесь как разработчик: https://chrome.google.com/webstore/devconsole. Регистрация стоит $5 (один раз), нужна двухэтапная аутентификация Google-аккаунта.
2. **New item** → загрузите `soundcloud-downloader-chrome-<версия>.zip`.
3. Вкладка **Store listing**:
   - язык: русский;
   - описание и краткое описание: тексты ниже;
   - категория: *Tools* (Инструменты);
   - иконка: `store/icon-128.png`;
   - скриншоты: `store/screenshot-1-page.png`, `screenshot-2-popup.png`, `screenshot-3-options.png`;
   - Small promo tile: `store/promo-small-440x280.png`;
   - Marquee: `store/promo-marquee-1400x560.png`;
   - сайт и поддержка: ссылка на репозиторий или issues.
4. Вкладка **Privacy practices**:
   - Single purpose — текст ниже;
   - Permission justification — по разрешению, тексты ниже;
   - Remote code: **No, I am not using remote code**;
   - Data usage: ничего не отмечать, расширение не собирает данные. Поставить все три галочки соответствия;
   - Privacy policy URL — см. выше.
5. Вкладка **Distribution**: бесплатно, видимость *Public* или *Unlisted*, регионы — все.
6. **Submit for review.** Проверка обычно занимает от 1 до 7 дней, иногда дольше.
7. **Обновления:** поднимите версию, соберите пакет, затем Package → Upload new package → Submit.

## Microsoft Edge Add-ons

1. Зарегистрируйтесь в Partner Center (бесплатно): https://partner.microsoft.com/dashboard/microsoftedge.
2. **Create new extension** → загрузите тот же `soundcloud-downloader-chrome-<версия>.zip`.
3. Availability: Public или Hidden. Properties: категория *Productivity*, ссылка на политику конфиденциальности.
4. Store listing: русский язык, тексты и картинки те же, что для Chrome.
5. **Publish.** Проверка обычно до 7 рабочих дней.

## Firefox Add-ons (AMO)

1. Войдите с аккаунтом Mozilla: https://addons.mozilla.org/developers/.
2. **Submit a New Add-on**. Выберите способ распространения:
   - **On this site** — публичный листинг, нужна ручная проверка;
   - **On your own** — Unlisted: подпись приходит автоматически, установка по своей ссылке на `.xpi`.
3. Загрузите `soundcloud-downloader-firefox-<версия>.zip`. Исходники отдельно прикладывать не нужно: код не минифицирован и не собирается сборщиком.
4. Для листинга: название, описание (тексты ниже), категория *Download Management*, ссылка на политику конфиденциальности, скриншоты из `store/`.
5. **Автоматически, из релиза.** Создайте API-ключи (Developer Hub → Tools → Manage API Keys) и добавьте их в секреты репозитория как `AMO_JWT_ISSUER` и `AMO_JWT_SECRET`. Тогда каждый тег `v*` будет сам подписывать `.xpi` (канал unlisted) и прикладывать его к релизу GitHub.

   Вручную то же самое:

   ```bash
   npx web-ext@8 sign --source-dir firefox --channel unlisted --api-key <issuer> --api-secret <secret>
   ```

## Opera Add-ons (по желанию)

https://addons.opera.com/developer/ — загружается тот же Chrome-пакет. Проверка медленная, от нескольких недель.

## Тексты для листинга

**Название:** SoundCloud Downloader

**Краткое описание** (до 132 символов):

> Скачивайте треки, альбомы и плейлисты SoundCloud в лучшем качестве — с обложкой, тегами и текстом песни. Плейлисты одним ZIP.

**Полное описание:**

```text
Кнопка «Скачать» прямо на SoundCloud: на страницах треков, плейлистов и альбомов, у каждого трека в ленте и поиске, в шапке подборок Discover и в нижнем плеере.

• Лучшее качество: оригинальный файл автора (WAV/FLAC/MP3 320), если он разрешил скачивание, или лучший поток SoundCloud (AAC 160 kbps, с Go+ — до 256 kbps).
• Обложка, исполнитель, название, альбом, год, жанр, номер трека и текст песни — прямо в файле (MP3, M4A, FLAC, Ogg/Opus, WAV).
• Плейлисты, альбомы и все треки профиля — одним ZIP-архивом с обложкой и плейлистом .m3u8.
• Вставка ссылок (в том числе on.soundcloud.com), очередь загрузок с прогрессом, повтор и отмена.
• Шаблоны имён файлов и папок, выбор кодека, размер обложки.

Без входа скачивается большинство треков; вход на soundcloud.com открывает оригинальные файлы и качество Go+.
Треки с DRM и превью Go+ без подписки сохранить нельзя — расширение честно сообщает причину.

Расширение бесплатное, без рекламы и аналитики, не собирает данные и обращается только к серверам SoundCloud.
Только для личного использования: уважайте права авторов. Проект не связан с SoundCloud.
```

**Single purpose (единственное назначение):**

> Скачивание треков, альбомов и плейлистов с soundcloud.com в аудиофайлы с обложкой и тегами.

### Обоснования разрешений

| Разрешение | Обоснование |
|---|---|
| `downloads` | Сохраняет скачанные треки, ZIP-архивы плейлистов, обложку и плейлист `.m3u8` в папку загрузок пользователя. |
| `storage` | Хранит настройки пользователя (шаблоны имён, качество, папка) и кэш служебного идентификатора клиента SoundCloud. |
| `cookies` | Читает cookie сессии `oauth_token` сайта soundcloud.com, чтобы запросы к API SoundCloud шли от имени вошедшего пользователя: так доступны оригинальные файлы и полные версии треков. Cookie отправляется только на `api-v2.soundcloud.com`. |
| `contextMenus` | Добавляет пункт «Скачать с SoundCloud» в контекстное меню ссылок и страниц soundcloud.com. |
| `offscreen` (только Chrome) | Service worker в Manifest V3 не умеет создавать Blob URL. В offscreen-документе собирается аудиофайл с тегами и ZIP перед передачей в `downloads`. |
| Хост `soundcloud.com`, `*.soundcloud.com` | Кнопки «Скачать» на страницах сайта, данные треков со страницы, запросы к API SoundCloud (`api-v2.soundcloud.com`). |
| Хосты `*.sndcdn.com`, `*.soundcloud.cloud` | Серверы SoundCloud, где лежат обложки и аудиопотоки. Отсюда скачиваются файлы. |
| Content scripts на soundcloud.com, включая скрипт в контексте страницы (MAIN world) | Встраивают кнопки и читают данные, которые загружает сам сайт: списки треков и ссылку на поток из плеера. Удалённый код не загружается, весь код лежит в пакете. |
